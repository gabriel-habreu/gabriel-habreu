## 🧠 Sobre mim

Sou estudante de **Desenvolvimento de Sistemas na Etec de Hortolândia**, construindo minha base através de projetos acadêmicos, experimentação prática e desenvolvimento contínuo.

Atualmente, meu foco está em entender cada vez melhor o que acontece **por baixo dos panos**:

- 🖥️ Explorar **Terminal, CLI e sistemas operacionais**
- ⚙️ Entender **arquitetura de aplicações e servidores**
- 🗄️ Trabalhar com **processamento e organização de dados**
- 🔧 Desenvolver uma base mais sólida em **Backend**
- 📱 Experimentar desenvolvimento **mobile e frontend**
- 🧪 Aprender construindo e desmontando projetos para entender como funcionam

Um dos principais projetos em desenvolvimento é o **GlicoVoz**, meu TCC, no qual venho trabalhando com tecnologias de software e explorando diferentes abordagens para processamento de informações.

> Meu objetivo não é apenas aprender frameworks. É construir uma base que permita entender a tecnologia por trás deles.
